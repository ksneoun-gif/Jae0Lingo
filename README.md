# 재오링고 3D UI 개편본

## 바로 실행
`index.html`을 브라우저로 열면 개인 학습 게임을 사용할 수 있습니다. 스타일과 사슴 이미지는 모두 폴더에 포함되어 있어 CDN 연결이 필요 없습니다.

서버로 실행하려면 이 폴더에서:

```sh
npm start
```

브라우저: http://localhost:4173
같은 네트워크 기기에서는 실행 중인 컴퓨터의 IP 주소와 4173 포트로 접속합니다. 서로의 진도는 공유되지 않습니다.

## 변경한 화면
- 시작: 사슴 3D 렌더, 입체 받침대, 떠 있는 XP와 하트, 닉네임 입력
- 지도: 입체 학습 발판, 장식 섬, 점선 경로, 진도 표시
- 문제: 에디 캐릭터, 큰 선택 버튼, 눌림 효과, 정답·오답 해설
- 결과: 에디 캐릭터, 별·XP, 연속 정답 표시
- 작은 화면에 맞춘 레이아웃과 키보드 선택 지원
- 단계 완료 진도를 브라우저에 저장하고 새로고침 뒤 이어가기
- 체력 소진 뒤 무료 재도전

## 캐릭터
첨부 IMG_0347.HEIC 사슴을 참조하여 Gemini에서 생성했습니다.
Higgsfield는 계정의 Basic 이상 요금제 제한으로 생성을 거절했습니다.
`assets/eddie-3d.jpeg`는 3D처럼 렌더링된 1024px 이미지이며, 회전 가능한 GLB/FBX 모델은 아닙니다.

## 운영 사이트 반영
이 폴더를 정적 사이트로 배포하거나, Node 서비스의 시작 명령을 `npm start`로 지정합니다.
Render의 PORT 환경변수를 자동으로 사용합니다. 런타임 외부 패키지가 필요 없습니다.
기존 사이트가 다른 서버 기능을 가지고 있다면 HTML/CSS/캐릭터 UI 변경분을 그 저장소에 병합해야 합니다.
현재 onrender.com 사이트 자체는 수정하지 않았습니다. 연결 저장소가 제공되어야 기존 주소에 반영할 수 있습니다.

## 범위와 확인
이 버전은 사용자가 지정한 공개 게임 및 바탕화면 index.html의 UI 개편본입니다.
해당 게임은 개인 학습형이고 실시간 방·순위·관리자와 연결되지 않은 상태였습니다.
이번 버전은 실시간 멀티플레이 구현 완료본이 아닙니다.
기존 10개 스테이지/30문항을 유지했습니다. 2주차 7개 개념 순서로 문제 전체를 재편한 버전은 아닙니다.

디자인 구조와 데이터 모델은 DESIGN.md에 있습니다.
스타일을 수정한 뒤 유틸리티를 추가했다면 `npm install` 후 `npm run build:css`로 다시 생성합니다.
